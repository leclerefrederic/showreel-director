# Trailers

Online: https://leclerefrederic.github.io/showreel-director/demo/showreel-director-trailer.html and https://leclerefrederic.github.io/showreel-director/demo/showreel-studio-trailer.html

They live next to the skill, not inside the `.skill` package, so the package stays light and does not carry the music. The skill offers the Director trailer only when this folder is present next to it; otherwise it points to the project repository.

- `showreel-director-trailer.html`: a ~90 s self-contained showreel (16 scenes, 16:9 and 9:16, English on screen) that explains this skill. Built with the skill itself from an interview-style brief, kinetic type and flashes on the beat, music Deep-Space Funk.
- `showreel-studio-trailer.html`: a ~89 s release trailer for the Showreel Studio app (17 scenes, 16:9 and 9:16, English on screen), built with skill 0.15.0 in the scene-file format as a non-regression test. Acid palette, pale shapes that move on the beat and pulse with the kick, music Funk Groove.

- Open in a browser, click "Start with sound". Controls: pause, seek, mute/volume, replay, format switch.
- They are examples of what the skill can produce, not templates: never reuse their look unless the user picks it.
- Music: Deep-Space Funk and Funk Groove, generated with Suno, used here for non-commercial purposes only (Suno's terms apply; the user states this project is non-commercial). Do not reuse the tracks commercially, and check Suno's terms again before any commercial use of a reel. Fonts: Liberation Sans Narrow Bold and Liberation Mono Bold (Director trailer); Unbounded and Space Grotesk, Latin subsets under the SIL OFL (Studio trailer). Confirm the font licences before publishing.
- The tracks are embedded, so each file weighs about 3 MB.
