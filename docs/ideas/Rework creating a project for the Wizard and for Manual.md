# Rework creating a project for the Wizard and for Manual

2026-11-10 (owner), backlog: rework the experience of creating a project, for the Wizard (with Clap) and for Manual (without), each simple and fluid and using the room of the window. Principle: a visual choice is made with the app's visual picker (looks board, palettes, font specimens, backgrounds, moods), never as text options in the chat; in the Wizard Clap opens the picker, preselects or highlights an option with a reason, and the owner decides by clicking. Possible shared skeleton of steps (Film, Look, Brief, Resources, Scenes, Music) with the viewer showing the design system live. Needs a typed way for Clap to present a picker (kind, preselection, reason) and receive the choice as a proposal. Details and the owner's remarks: docs/ux-notes.md, section "Project and wizard". Not a brief yet: ask the owner what bothers him in each way in first.
