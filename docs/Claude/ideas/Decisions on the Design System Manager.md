# Decisions on the Design System Manager

2026-11-10 (owner), decisions on the Design System Manager above: (1) the user is the guarantor of the usage rights of licensed resources, so approvals and rights answers travel with the package; (2) a package is exported as one archive file (a zip with its own extension, to be chosen: the project already has a hidden `.studio/` folder, so a different extension avoids confusion); (3) the AI may read design decisions, the user's corrections and the journal of a reel to improve a package, never the content of texts or files; (4) a package can also be handed to the skill, to feed its style sheet.
