# An item's timing is written in seconds

**Decision.** The moment an item appears and disappears is written in seconds from the start of the scene, as built in W4. Beats may be shown beside the field as a helper, never as the stored unit.

**Why.** The file, the checks and the build message already speak seconds; the owner accepted the recommendation of QUESTION-015, 2026-11-11.
