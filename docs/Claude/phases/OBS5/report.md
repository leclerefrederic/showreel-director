One thing to know about the rebuild: the freshness guard (`tools/build_fresh.sh`) first refused ("build is stale: PackageViews.swift has changed since the binary was built"). A comment-only change compiles to a byte-identical binary that the linker does not rewrite, so the guard, which compares content with the last stamp, saw changed sources and an old binary. I deleted the old release binary in the build folder (outside the repo) so that the build linked a fresh one, and the guard then passed; I did not touch the guard.
