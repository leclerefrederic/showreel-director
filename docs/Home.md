## The reference documents (hubs)

Each one keeps its old path and its numbered or named headings; the text is in the atomic notes it links to.

- [[studio-spec]]: the design of Showreel Studio v2. The notes are in `spec/` (section 10 lists the phases as planned, section 11 the decisions the owner validated).
- [[ux-notes]]: the owner's UX remarks per block, and what each phase built from them. The notes are in `ux/`.
- [[phases-done]]: the one table of every phase, with its prompt, its report and its versions.
- [[ideas]]: the parking lot, and the open questions the owner has not settled yet (read the section "Questions to settle with the owner" before writing any prompt).

## Dashboards

The dashboards and the map are in `dashboards/`; they are for Obsidian only.

- [[Phases.base]]: every phase, newest first.
- [[Decisions.base]]: what the owner decided, and what was superseded.
- [[Open questions.base]]: the questions still open, from the notes of `questions/`.
- [[Ideas.base]]: the ideas, one note each in `ideas/`, newest first, by area, and the ones wanted soon.
- [[Architecture map.canvas]]: the repository, the skill, the app and the documentation on one page.

## Phases

One folder per phase that has a prompt or a report: `phases/<ID>/prompt.md` (the file Claude Code reads) and `phases/<ID>/report.md` (what it found, built and left to check). The early phases, which only have a summary, are flat notes in `phases/early/`. Start from the table in [[phases-done]]. The batch and overnight reports that span several phases are in `archive/`: [[archive/batch-report]], [[archive/batch2-report]], [[archive/BATCH-A/report]], [[archive/overnight-report]].

## For agents

[[Index]] is the agent view: one line per note, generated from the properties, never edited by hand. An agent reads it first and opens only the note it needs. Never read `.base` or `.canvas` files.

## Notes by kind

- Decisions: the notes in `decisions/`, listed by [[Decisions.base]].
- Questions: the notes in `questions/`, listed by [[Open questions.base]].
- Ideas: the notes in `ideas/`, listed by [[Ideas.base]].

## Outside the vault

- `CLAUDE.md` at the root: the rules every agent follows.
- `ROADMAP.md`: features and known limits.
- `CHANGELOG-APP.md` and `RELEASE-NOTES-APP.md`: what each app version changed.
- `showreel-director/evals/RESULTS.md`: test runs of the skill.
