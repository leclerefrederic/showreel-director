# Glossary: technical terms vs everyday language

Purpose: understand people who do not come from video, editing or motion design, and put the right words in the brief, storyboard and scene cards. How to use it:

1. **Read intent, not the word.** Everyday words often cover several technical things (see "Everyday phrases" and "Words that mean two things").
2. **Keep the user's word in conversation.** In documents use the precise term and put the user's word in brackets the first time: "scene (your slide)".
3. **Restate once, only when it matters.** Say "I'll call this a scene" if the precise meaning changes what you build; otherwise translate silently. Never correct tone or make the user feel behind.
4. **Ask one short question when two readings lead to different work**, offering both readings by name with a one-line example.
5. **Explain on request in one or two lines**, with an example from the user's own project, then point here for the rest.

## 1. Everyday phrases → what they usually mean → what to settle
| Everyday phrase | Usual meaning | Settle with the user |
|---|---|---|
| "a video", "a presentation video" | Showreel, teaser, explainer or product film | Purpose, audience, length, where it plays |
| "slides", "pages", "screens", "clips" | Scenes | Scene count and what each one carries |
| "the intro", "the opener" | Hook, or a title card | Job: grab attention, or name the thing? |
| "the ending", "the last message" | End card and/or CTA | Closing line, logo, URL, what to do next |
| "an effect", "an animation" | Text animation, transition, camera move, graphic treatment, key-moment reveal | Which category; show candidates |
| "a transition" | Cut, dissolve, wipe, slide, flash, or any effect between scenes | Hard or soft, on a beat or not |
| "zoom" | Push-in (camera moves closer) or scale (picture grows) | Smooth and continuous, or a quick punch |
| "fade" | Fade in/out (from or to black or colour) or cross-fade (between scenes) | Which direction, how long |
| "make it flow", "smooth" | Soft easing, overlapping motion, longer transitions | Where it should feel smooth vs sharp |
| "punchy", "bang", "pop", "hits hard" | High energy, fast easing, impact accents, flashes, shake | How many impact moments, where the peak sits |
| "slick", "clean", "polished", "premium" | Restraint, alignment, consistent spacing, few effects done well | Reference examples, what to avoid |
| "fun", "playful" | Bounce, overshoot, humour, bright accents | How far: gentle or cartoonish |
| "modern", "techy", "cool" | A set of attributes, not one look | What shows it: type, motion, colour, sound |
| "vibe", "atmosphere", "ambiance" | Mood: palette, pace, music, contrast | One reference film or image |
| "soul", "emotion", "impact" | Intended feeling, tension shape, one memorable moment | Feeling, from → to, the peak |
| "rhythm", "tempo", "energy" | Pacing (cut speed) and/or music tempo | Cut speed vs track speed |
| "on the beat", "sync it", "to the music" | Cuts and hits on beats, strong moments on downbeats or drops | Which moments carry the sync |
| "it should breathe" | Holds, pauses, silence between ideas | Where the calm sits |
| "too busy", "too much" | Too many things at once, too fast, too much text | Which scene; what to cut first |
| "too small", "can't read it" | Text size, contrast, time on screen, or safe zone | Size vs duration vs contrast |
| "make it bigger" | Larger type or element, within safe zones | How big; what else must stay visible |
| "logo animation", "logo reveal" | Logo sting or stinger | Brand rules for logo use and motion |
| "background music", "a soundtrack" | A music track under the film | Own track, licensed, generated; rights |
| "voice", "narration" | Voice-over | Recorded, synthetic or none; language |
| "subtitles" | Subtitles (translate speech) or captions (also describe sound) or just on-screen text | Spoken words to transcribe, or none |
| "high quality", "HD", "4K" | Resolution and bitrate, not creative quality | Where it plays; file weight limits |
| "export it", "send me the video" | Render a video file (MP4) or deliver an HTML player | What the tools can produce here |
| "loop it", "play on repeat" | Seamless loop: last frame leads to first | Replay button vs true loop |
| "a version for phones", "stories" | Portrait 9:16 format | Re-composed scenes or mapped layout |
| "quick version", "cut-down", "teaser of it" | Shorter edit (15 s, 30 s) | Which scenes survive |
| "v1", "draft", "final" | Rough cut, revision, final cut / picture lock | What is still open to change |

## 2. Words that mean two things
| Word | Meaning A | Meaning B | Default in this skill |
|---|---|---|---|
| Beat | One pulse of the music | A story moment (a "story beat") | Music pulse; say "story beat" for the other |
| Cut | Instant change between shots | To remove content ("cut that line") | Ask if unclear |
| Frame | One still image of the film | The edge of the picture or a visible border | One still image |
| Scene | One storyboard unit in this skill | A film scene (one place and time) | One storyboard row |
| Sequence | A chapter of several scenes | A series of animations on one element | Chapter |
| Transition | Scene-to-scene change | Any element changing state | Scene-to-scene |
| Effect | An animation or treatment | A sound effect | Animation; say "sound effect" |
| Montage | The whole editing job | A fast series of shots | Fast series |
| Render | Compute the final frames | Draw one frame live in the player | Say which |
| Export | Write the final file | Save the project | Final file |
| Layer | A stacked picture or element | A track in the audio mix | Picture layer |
| Mask | Shape that hides or reveals part of a layer | Clipping a text reveal | Shape reveal |
| Resolution | Pixel size of the picture | Sharpness on screen | Pixel size |
| Length / duration | Total running time | Time one element stays on screen | Total, unless "on screen" is said |
| Format | Aspect ratio (16:9, 9:16) | File type (MP4, GIF, HTML) | Ask which |
| Font | The file you use | The type family | Same for most uses; use "typeface" for the design |
| Style | The overall look | A text or animation style | Overall look |
| Drop | The moment the full beat returns | An element falling (drop in) | Musical drop; "drop in" for falling |
| Hit | An accented sound or visual impact | A successful result | Impact |
| Cue | A signal that triggers something | A timed music or audio entry | Timed trigger |
| One-take | One long continuous shot with no cuts | Any single-scene film | Rare; always confirm before assuming |

## 3. Easily confused pairs
| Pair | Difference |
|---|---|
| Shot vs scene vs sequence | A shot is one uncut piece; a scene is one idea (one or several shots); a sequence is several scenes forming a chapter. |
| Animation vs motion graphics vs motion design | Animation is the broad term; motion graphics are animated type, shapes and graphics (not filmed); motion design is the craft of designing them. |
| Push-in vs zoom | Push-in moves the camera closer (perspective changes); zoom scales the picture or changes focal length. |
| Cross-fade vs fade | Cross-fade blends two scenes; fade goes to or from black or a colour. |
| Wipe vs slide | A wipe is an edge that reveals the next scene; a slide moves the whole scene or panel. |
| Subtitles vs captions | Subtitles translate speech; captions also describe sounds (accessibility). |
| Resolution vs bitrate vs file weight | Pixel size vs data per second vs total megabytes. |
| Aspect ratio vs resolution | Shape of the frame vs number of pixels in it. |
| Vector vs raster | Vector is drawn from shapes and stays sharp at any size; raster is pixels. |
| Typeface vs font | Design family vs a specific file or style of it. |
| Tracking vs kerning vs leading | Spacing of all letters / of one pair / between lines. |
| Easing vs speed | Easing is how speed changes; speed is how fast overall. |
| Pacing vs tempo | Pacing is how fast scenes change; tempo is the music's BPM. |
| Mute vs silence | Mute is the viewer's switch; silence is a deliberate quiet in the sound design. |
| Loop vs replay | Loop restarts automatically and seamlessly; replay restarts on request. |
| Draft vs final vs picture lock | Work in progress; finished edit; point after which timing is frozen. |
| Storyboard vs animatic | Scene plan on paper; plan played with timing and sound. |
| Brief vs script | Decisions for the project; the words and actions in it. |

## 4. Structure of a film
| Term | Meaning |
|---|---|
| Shot | One continuous piece of picture between two cuts. |
| Scene | One idea or place made of one or several shots. In this skill: one storyboard row (S01, S02…), the unit of review. |
| Sequence | A group of scenes that forms a chapter (hook, method, finale). |
| Storyboard | Scene-by-scene plan with time, text, image and motion. |
| Animatic | Storyboard played with timing and sound before final art. |
| Script | The words and actions. |
| Voice-over / narration | Spoken commentary over the picture. |
| Hook | First seconds meant to stop the viewer. |
| CTA (call to action) | The closing request: visit, try, contact. |
| End card | Last screen with logo, URL, contact. |
| Title card | Screen that carries only a title. |
| Lower third | Name or caption banner in the lower part of the frame. |
| Teaser | Short film that creates curiosity. |
| Explainer | Film that explains how something works. |
| Showreel / reel | Piece that shows capabilities or a product. |
| Moodboard | Collage of references for look and feeling. |
| Brief | Written decisions that start production. |
| Deliverable | A file or output handed over. |
| B-roll / footage | Supporting filmed material / any filmed material. |
| Asset | Any supplied or produced ingredient: logo, font, image, track, data. |

## 5. Editing and transitions
| Term | Meaning |
|---|---|
| Cut | Instant change from one shot to the next. |
| Cut on beat | A cut placed exactly on a musical beat. |
| Hard cut / smash cut | Abrupt cut / abrupt cut from calm to loud or the reverse. |
| Dissolve / cross-fade | Next scene fades in while the previous fades out. |
| Fade in / out, dip to black | Picture appears from or goes to black or a colour. |
| Wipe | A moving edge reveals the next scene. |
| Flash cut | Cut hidden by a white flash. |
| Match cut | Cut where shape, position or movement continues across scenes. |
| Jump cut | Cut inside the same shot that makes the picture jump. |
| J-cut / L-cut | Sound of the next scene starts before its picture / sound of the previous continues over the next picture. |
| Speed ramp | Speed changes smoothly within a shot. |
| Freeze frame | Picture stops on one frame. |
| Montage | Editing as a whole; also a quick series of shots. |
| Pacing | How fast scenes change and information arrives. |
| Timeline / timecode | The time axis / a position on it (mm:ss or frames). |
| Rough cut / final cut / picture lock | First assembly / finished edit / timing frozen. |
| Handoff | Visual link from one scene to the next (shape, colour or motion continues). |

## 6. Motion and animation
| Term | Meaning |
|---|---|
| Motion design / motion graphics | Animated graphics, type and shapes (not filmed). |
| Kinetic typography | Text that moves and is the main visual. |
| Keyframe | A defined state at a moment; the software fills the in-between. |
| Easing (ease in, ease out) | How speed changes over time: starts slow / ends slow. |
| Overshoot | Goes slightly past its target then returns. |
| Bounce / elastic | Rebounds / springs at the end. |
| Anticipation | A small opposite move before the main move. |
| Squash and stretch | Shape deforms to suggest weight or speed. |
| Stagger | Elements start one after another. |
| Slam | Text lands very large and fast with impact. |
| Reveal | An element becomes visible (mask, wipe, fade, scale). |
| Mask | Shape that hides or reveals part of an element. |
| Push-in / pan / tilt / dolly | Camera moves closer / sideways / up-down / forward-backward. |
| Parallax | Layers move at different speeds for depth. |
| Motion blur | Soft smear on fast movement. |
| Particles | Many small elements: confetti, sparks, dust. |
| Easter egg | Small hidden gag for those who watch closely. |
| Loop | Plays again seamlessly from the start. |
| Looping idle | Small continuous movement that keeps a still scene alive. |
| Persistent character | An element that keeps the same identity across scenes. |

## 7. Visual treatments
| Term | Meaning |
|---|---|
| Glow / bloom | Soft light around bright areas. |
| Vignette | Darkened edges that focus the eye. |
| Film grain / noise | Fine texture over the picture. |
| Chromatic aberration / RGB split | Colour channels slightly offset. |
| Glitch | Deliberate digital distortion (slices, jitter, offsets). |
| Scanlines / CRT | Horizontal line texture imitating old screens. |
| Halftone / duotone | Dot pattern / two-colour image. |
| Drop shadow / long shadow | Soft shadow below / hard shadow stretching away. |
| Blend mode | How a layer mixes with those under it (screen, multiply, difference). |
| Opacity / alpha | How transparent an element is. |
| Gradient | Smooth blend between colours. |
| Color grading | Adjusting colours for mood. |
| Negative space | Empty area that gives room to the subject. |
| Grid | Invisible structure for aligning elements. |
| Safe zone / safe margin | Area where text stays visible on any screen or app overlay. |

## 8. Typography and colour
| Term | Meaning |
|---|---|
| Typeface / font | The design family / the file used. |
| Weight, width | Thin to black / condensed to extended. |
| Serif / sans serif / monospace | With small strokes at letter ends / without / every letter equal width. |
| Tracking / kerning / leading | Spacing between all letters / one pair / lines. |
| Hierarchy | What the eye reads first, second, third. |
| Contrast | Difference of light or colour between text and background. |
| Legibility / readability | Can each letter be told apart / can the text be read comfortably. |
| Palette | The set of colours used. |
| Accent colour | The colour reserved for emphasis. |
| Copy | The written words on screen. |
| Headline / subline | Main line / secondary line under it. |

## 9. Picture, format and files
| Term | Meaning |
|---|---|
| Aspect ratio | Width : height. 16:9 landscape, 9:16 portrait (phones, stories), 1:1 square. |
| Resolution | Pixels in the frame (1920×1080 = Full HD, 3840×2160 = 4K). |
| Frame rate (fps) | Images per second (24 film, 30 or 60 screens). |
| Render / export | Producing the final file from the project. |
| Codec / bitrate | How the file is compressed / how much data per second. |
| MP4 / WebM / GIF | Common video file / web video file / short silent looping image. |
| HTML player | A self-contained web page that plays the film in a browser. |
| Canvas / WebGL / SVG | Browser drawing surface / browser 3D drawing / vector image file. |
| Vector / raster | Drawn from shapes / made of pixels. |
| Alpha channel | Transparency stored in an image. |
| Contact sheet | A grid of frames to check a film at a glance. |
| Placeholder | Temporary stand-in for a missing asset, flagged on screen. |

## 10. Music and sound
| Term | Meaning |
|---|---|
| BPM | Beats per minute (tempo). |
| Beat | One pulse of the music. |
| Bar | Group of beats, usually 4. Length in seconds = 240 / BPM. |
| Downbeat | First beat of a bar, the strongest place to cut. |
| Breakdown | Part where the music strips back (often drums or bass out). |
| Build-up / riser | Rising tension before a hit. |
| Drop | The moment the full beat returns after a build-up. |
| Bridge | Contrasting section before the final part. |
| Intro / outro | Opening / closing part of a track. |
| Stem | A separate layer of a track (drums, bass, voice). |
| SFX / sound design | Sound effects (hit, whoosh, click) added on top of music. |
| Stinger | Short musical or sound accent, also a short animated logo piece. |
| Loudness (LUFS) | Perceived volume standard (EBU R128). |
| Sync | Picture events landing on audio events. |
| Fade-out | Volume falls to silence at the end. |
| Licence / rights | Permission to use a track, font or image (personal, non-commercial, commercial). |

## 11. Accessibility
| Term | Meaning |
|---|---|
| Reduced motion | A calmer version for people sensitive to movement. |
| Flashing limit | No more than 3 flashes per second (WCAG 2.3.1). |
| Captions | On-screen text for speech and meaningful sounds. |
| Contrast ratio | Measured text-to-background contrast (WCAG 1.4.3). |
| Muted viewing | Film must still be understood with the sound off. |

## 12. Review and process
| Term | Meaning |
|---|---|
| Round / revision | One cycle of feedback and changes. |
| Sign-off / approval | Explicit OK that lets the next step start. |
| Feasibility check | Test that duration, scene count, text and formats can work together. |
| Release gate | List of items to resolve before sharing the film. |
| WIP | Work in progress. |
| Reference | An existing film, image or site that shows a wanted quality. |
| OK / MODIFY / DITCH | The decisions available in the scene review: keep, change, drop. |
