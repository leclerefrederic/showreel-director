# Glossary: video, editing and motion vocabulary

Use this to understand everyday or imprecise words from people who do not come from editing or video, and to name things correctly in the brief and storyboard. The user's own word always wins in conversation: translate silently, or restate once ("I'll call this a scene") when the precise term changes what you build. Never correct tone or make the user feel behind.

## Structure of a film
| Term | Meaning | Often said instead |
|---|---|---|
| Shot | One continuous piece of picture between two cuts. | clip, take, slide |
| Scene | One idea or place made of one or several shots. In this skill: one storyboard row (S01, S02…), the unit of review. | slide, part, screen, shot |
| Sequence | A group of scenes that form a chapter (hook, method, finale). | part, act, section |
| One-take | One single shot with no cut, usually long. A rare, specific technique: ask before assuming it. | scene, shot |
| Storyboard | Scene-by-scene plan with time, text, image and motion. | visual script, shot list |
| Animatic | Storyboard played with timing and sound, before final art. | |
| Script | The words and actions. | |
| Voice-over / narration | Spoken commentary over the picture. | |
| Hook | First seconds meant to stop the viewer. | intro, opener |
| CTA (call to action) | The closing request: visit, try, contact. | the ending, the last message |
| End card | Last screen with logo, URL, contact. | outro, credits |
| Title card | Screen that carries only a title. | |
| Lower third | Name or caption banner in the lower part of the frame. | caption, banner, subtitle |
| Teaser | Short film that creates curiosity. | |
| Showreel / reel | Compilation or presentation piece showing capabilities. | demo, presentation video |
| Moodboard | Collage of references for look and feeling. | inspiration board |
| Brief | Written decisions that start production. | |

## Editing and transitions
| Term | Meaning | Often said instead |
|---|---|---|
| Cut | Instant change from one shot to the next. | hard transition |
| Cut on beat | A cut placed exactly on a musical beat. | sync to the music |
| Transition | Any way of passing from one scene to the next (cut, dissolve, wipe, slide…). | effect |
| Dissolve / cross-fade | Next scene fades in while the previous fades out. | fade |
| Fade in / out, dip to black | Picture appears from or goes to black or a colour. | |
| Wipe | A moving edge reveals the next scene. | sweep |
| Flash cut | Cut hidden by a white flash. | flash |
| Match cut | Cut where shape, position or movement continues across scenes. | |
| Jump cut | Cut inside the same shot that makes the picture jump. | |
| Montage | Editing as a whole; also a quick series of shots. | |
| Pacing | How fast scenes change and information arrives. | rhythm, tempo, energy |
| Timeline | The time axis of the project. | |
| Timecode | Position in time, mm:ss or frames. | |
| Rough cut / final cut / picture lock | First assembly, finished edit, point after which timing no longer changes. | v1, final version |

## Motion and animation
| Term | Meaning | Often said instead |
|---|---|---|
| Motion design / motion graphics | Animated graphics, type and shapes (not filmed). | animation |
| Kinetic typography | Text that moves and is the main visual. | animated text |
| Keyframe | A defined state at a moment; the software fills the in-between. | |
| Easing | How speed changes over time (ease in = starts slow, ease out = ends slow). | acceleration, smoothness |
| Overshoot | Goes slightly past its target then returns. | bounce |
| Bounce / elastic | Rebounds or springs at the end. | spring |
| Stagger | Elements start one after another. | cascade |
| Slam | Text lands very large and fast with impact. | pop, bang |
| Push-in vs zoom | Camera moves closer (push-in) vs picture simply scaled (zoom). | zoom |
| Pan / tilt / dolly | Camera moves sideways / up-down / forward-backward. | |
| Parallax | Layers move at different speeds for depth. | |
| Motion blur | Soft smear on fast movement. | |
| Particles | Many small elements (confetti, sparks, dust). | glitter, sparkles |
| Easter egg | Small hidden gag for those who watch closely. | |
| Loop | Plays again seamlessly from the start. | repeat |
| Vector / raster | Drawn from shapes (sharp at any size) / made of pixels. | |
| Alpha / transparency | Transparent background of an image. | transparent background |

## Picture and format
| Term | Meaning |
|---|---|
| Aspect ratio | Width : height. 16:9 landscape, 9:16 portrait (phone, stories), 1:1 square. |
| Resolution | Pixels in the frame (1920×1080 = Full HD). |
| Frame / fps | One image / images per second (24 film, 30 or 60 screens). |
| Safe zone | Area where text stays visible whatever the screen or app overlay. |
| Render / export | Producing the final file from the project. |
| Codec / bitrate | How the file is compressed / how much data per second. |
| Contact sheet | A grid of frames to check a film at a glance. |

## Typography and colour
| Term | Meaning |
|---|---|
| Typeface / font | The design family / the file used. |
| Weight | Thin to black. |
| Tracking / kerning / leading | Spacing between all letters / between two letters / between lines. |
| Hierarchy | What the eye reads first, second, third. |
| Contrast | Difference of light or colour between text and background. |
| Palette | The set of colours used. |
| Accent colour | The colour reserved for emphasis. |

## Music and sound
| Term | Meaning |
|---|---|
| BPM | Beats per minute (tempo). |
| Beat | One pulse of the music. |
| Bar | Group of beats, usually 4. Length in seconds = 240 / BPM. |
| Downbeat | First beat of a bar, the strongest place to cut. |
| Breakdown | Part where the music strips back (often drums or bass out). |
| Build-up | Rising tension before a hit. |
| Drop | The moment the full beat returns after a build-up. |
| Bridge | Contrasting section before the final part. |
| Stem | A separate layer of a track (drums, bass, voice). |
| SFX / sound design | Sound effects (hit, whoosh, click) added on top of music. |
| Loudness (LUFS) | Perceived volume standard (EBU R128). |
| Sync | Picture events landing on audio events. |

## Feeling and intent (vague words, what to settle)
| Word a user may use | What to settle |
|---|---|
| punchy, high-energy, bang | Energy level, number of impact moments, where the peak sits. |
| slick, clean, polished | Spacing, alignment, restraint, polish of motion; fewer effects done well. |
| vibe, atmosphere | Mood, palette, music, pace; ask for a reference. |
| modern, cool | Perceived attributes: ask what shows it (type, motion, colour). |
| soul, emotion | Intended feeling, tension shape, one memorable moment. |
| an effect | Text animation, transition, camera, graphic treatment or key-moment reveal: offer the right category. |
