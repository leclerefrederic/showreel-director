# Glossary: video, editing and motion vocabulary (EN / FR)

Use this to understand everyday words from people who do not come from editing or video, and to name things correctly in the brief and storyboard. The user's own word always wins in conversation: translate silently, or restate once ("I'll call this a scene") when the precise term changes what you build. Never correct tone or make the user feel behind.

## Structure of a film
| Term (EN / FR) | Meaning | Often said instead |
|---|---|---|
| Shot / plan | One continuous piece of picture between two cuts. | "plan", "séquence", "slide", "clip" |
| Scene / scène | One idea or place made of one or several shots. In this skill: one storyboard row (S01, S02…), the unit of review. | "plan séquence", "slide", "partie", "écran" |
| Sequence / séquence | A group of scenes that form a chapter (hook, method, finale). | "partie", "acte" |
| One-take / plan-séquence | One single shot with no cut, usually long. A rare, specific technique. Almost never what is meant: ask. | used for "scene" or "shot" |
| Storyboard | Scene-by-scene plan with time, text, image, motion. | "script visuel", "plan de montage" |
| Animatic | Storyboard played with timing and sound, before final art. | |
| Script / scénario | The words and actions. Voice-over script = what is said. | |
| Voice-over / narration / voix off | Spoken commentary over the picture. | |
| Hook / accroche | First seconds meant to stop the viewer. | "intro qui claque" |
| CTA (call to action) | The closing request: visit, try, contact. | "la chute", "le message de fin" |
| End card / carton de fin | Last screen with logo, URL, contact. | "fin", "générique" |
| Title card / carton titre | Screen that carries only a title. | |
| Lower third / bandeau | Name or caption banner in the lower part of the frame. | "sous-titre", "bandeau" |
| Teaser | Short film that creates curiosity. | |
| Showreel / reel | Compilation or presentation piece showing capabilities. | "démo", "vidéo de présentation" |
| Moodboard | Collage of references for look and feeling. | "planche d'ambiance" |
| Brief | Written decisions that start production. | |

## Editing and transitions
| Term | Meaning | Often said instead |
|---|---|---|
| Cut / coupe | Instant change from one shot to the next. | "transition sèche" |
| Cut on beat | A cut placed exactly on a musical beat. | "caler sur la musique" |
| Transition | Any way of passing from one scene to the next (cut, dissolve, wipe, slide…). | "effet" |
| Dissolve / cross-fade / fondu enchaîné | Next scene fades in while the previous fades out. | "fondu" |
| Fade in / out, dip to black / fondu | Picture appears from or goes to black or a colour. | |
| Wipe / volet | A moving edge reveals the next scene. | "balayage" |
| Flash cut | Cut hidden by a white flash. | "flash" |
| Match cut / raccord | Cut where shape, position or movement continues across scenes. | |
| Jump cut | Cut inside the same shot that makes the picture jump. | |
| Montage | In French: the whole editing job. In English: a quick series of shots. | "le montage" |
| Pacing / rythme | How fast scenes change and information arrives. | "le peps", "le rythme" |
| Timeline | The time axis of the project. | |
| Timecode | Position in time, mm:ss or frames. | "à 0:42" |
| Rough cut / final cut / picture lock | First assembly, finished edit, point after which timing no longer changes. | "v1", "version finale" |

## Motion and animation
| Term | Meaning | Often said instead |
|---|---|---|
| Motion design / motion graphics | Animated graphics, type and shapes (not filmed). | "animation", "habillage" |
| Kinetic typography | Text that moves and is the main visual. | "texte animé" |
| Keyframe / image clé | A defined state at a moment; the software fills the in-between. | |
| Easing | How speed changes over time (ease in = starts slow, ease out = ends slow). | "l'accélération", "la souplesse" |
| Overshoot | Goes slightly past its target then returns. | "rebond" |
| Bounce / elastic | Rebounds or springs at the end. | "rebond", "ressort" |
| Stagger / décalage | Elements start one after another. | "en cascade" |
| Slam | Text lands very large and fast with impact. | "claque", "pop", "bang" |
| Push-in / zoom | Camera moves closer (push-in) vs picture simply scaled (zoom). | "zoom" |
| Pan / tilt / travelling | Camera moves sideways / up-down / forward-backward. | |
| Parallax | Layers move at different speeds for depth. | |
| Motion blur / flou de mouvement | Soft smear on fast movement. | |
| Particles | Many small elements (confetti, sparks, dust). | "cotillons", "paillettes" |
| Easter egg | Small hidden gag for those who watch closely. | |
| Loop | Plays again seamlessly from the start. | "en boucle" |
| Vector / raster | Drawn from shapes (sharp at any size) / made of pixels. | |
| Alpha / transparency | Transparent background of an image. | "fond transparent" |

## Picture and format
| Term | Meaning |
|---|---|
| Aspect ratio | Width : height. 16:9 landscape, 9:16 portrait (phone, stories), 1:1 square. |
| Resolution | Pixels in the frame (1920×1080 = Full HD). |
| Frame / fps | One image / images per second (24 film, 30 or 60 screens). |
| Safe zone | Area where text stays visible whatever the screen or app overlay. |
| Render / export | Producing the final file from the project. |
| Codec / bitrate | How the file is compressed / how much data per second. |
| Contact sheet / planche contact | A grid of frames to check a film at a glance. |

## Typography and colour
| Term | Meaning |
|---|---|
| Typeface / font | The design family / the file used. |
| Weight | Thin to black. |
| Tracking / kerning / leading | Spacing between all letters / between two letters / between lines. |
| Hierarchy | What the eye reads first, second, third. |
| Contrast | Difference of light or colour between text and background. |
| Palette | The set of colours used. |
| Accent colour | The colour reserved for emphasis. |

## Music and sound
| Term | Meaning |
|---|---|
| BPM | Beats per minute (tempo). |
| Beat | One pulse of the music. |
| Bar / mesure | Group of beats, usually 4. Length in seconds = 240 / BPM. |
| Downbeat | First beat of a bar, the strongest place to cut. |
| Breakdown / cassure | Part where the music strips back (often drums or bass out). |
| Build-up / montée | Rising tension before a hit. |
| Drop | The moment the full beat returns after a build-up. |
| Bridge / pont | Contrasting section before the final part. |
| Stem | A separate layer of a track (drums, bass, voice). |
| SFX / sound design | Sound effects (hit, whoosh, click) added on top of music. |
| Loudness (LUFS) | Perceived volume standard (EBU R128). |
| Sync | Picture events landing on audio events. |

## Feeling and intent (vague words, what to ask)
| Word the user may use | What to settle |
|---|---|
| "peps", "ça arrache", "pop", "bang" | Energy level, number of impact moments, where the peak sits. |
| "soigné", "propre" | Spacing, alignment, restraint, polish of motion; fewer effects done well. |
| "ambiance", "vibe" | Mood, palette, music, pace; ask for a reference. |
| "moderne", "cool" | Perceived attributes: ask what shows it (type, motion, colour). |
| "l'âme", "l'émotion" | Intended feeling, tension shape, one memorable moment. |
| "un effet" | Text animation, transition, camera, graphic treatment or key-moment reveal: offer the right category. |
